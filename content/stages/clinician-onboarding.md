# Current model

Move selected clinicians through administrative setup to readiness for matching. This is a provisional reference model, not a description of a specific company.

# Open questions

- What determines whether a clinician reaches productive practice quickly?
- Which steps are constraints rather than administrative necessities?

- What observable standard distinguishes administrative completion from readiness for real family matching?
- Which later defects indicate false readiness, and which outcomes would be unfair to attribute to onboarding?
- How should clinician comprehension, burden, confidence, and correction work balance activation speed?
